Orchard KB

Answer an open thread

Help someone who finds an unresolved question on discussions.apple.com. Orchard KB can publish a reviewed answer alongside the original thread link.

Submit an answer on GitHub

Before you submit

  1. Find the original Apple Discussions URL. Include it even if it no longer opens. Add a known archive link or the Orchard KB guide if one exists.
  2. Check for an existing submission using the thread ID. If one exists, add your evidence there.
  3. Use the issue form to describe the symptom, device and OS version, then give your proposed steps and what happened when you tried them. Include supporting references and say which steps are untested.

The submission is public and requires a GitHub account. Write in your own words and leave out account details, serial numbers and other personal information.

What happens next

A maintainer checks that the answer addresses the original symptom, looks for a reproducible result or supporting documentation, and records the versions the steps apply to. They may ask for more detail in the issue. Proposals stay open while evidence is missing.

When an answer is ready, it can be added to the relevant Orchard KB guide or published as a new guide. It will be marked as an Orchard KB contribution and linked to the public issue. The original Apple thread and any archived copy remain the historical record. A contribution does not change the accepted-answer status on Apple Discussions.

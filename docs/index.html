AirPods · Reviewed 2026-11-11

One AirPod is silent or quieter than the other

Check whether the affected earbud is charging, then test it on its own. A quiet earbud calls for a different check from one that never connects.

Applies to AirPods and AirPods Pro earbuds. Reset instructions depend on the model.

  1. Charge the case, put both earbuds inside and give them at least 30 seconds. Open the case near the paired iPhone or iPad and check the charging indicator for each earbud.
  2. Leave the working earbud in the closed case and play audio with the affected earbud in your ear. If it plays normally, put both earbuds back in the case briefly and then retest them together.
  3. For uneven volume, inspect the speaker mesh for debris and follow Apple’s cleaning instructions for your model. On iPhone or iPad, open Settings, then Accessibility, then Audio & Visual, and check that Balance is centred.
  4. If the earbud still fails, follow the reset instructions for your specific model. If it remains unresponsive, contact Apple Support for assessment.

One thread reports an earbud that appeared charged in the case but disappeared after removal. A reset was suggested, with no confirmed result from the original poster.

iCloud Photos · Reviewed 2026-11-11

iCloud Photos sync is paused or photos are missing

Read the library status in Photos before changing sync settings. It can tell you whether Photos is waiting for power, network access or iCloud storage.

Applies to iPhone, iPad and Mac using iCloud Photos. Where Photos shows sync status varies by OS version.

  1. Find the library status in Photos. On newer iPhone and iPad versions, check the profile button in Collections. On Mac, open Library and scroll to the bottom of All Photos.
  2. Follow the status message. For a pause associated with battery or network conditions, connect to power and Wi-Fi and let the device sync overnight.
  3. Verify that your devices use the same Apple Account. If you use Shared Photo Library, check which library view is selected.
  4. Keep iCloud Photos enabled while troubleshooting the pause.

The community reply includes a suggestion to toggle iCloud Photos. Apple advises keeping it enabled during sync troubleshooting. The steps here follow Apple’s guidance.

iPhone and iPad · Reviewed 2026-11-11

iPhone or iPad says Software Update Failed

Check compatibility, free space and network access before retrying. Note whether the failure happens while checking, downloading or installing.

Applies to Wireless iOS and iPadOS updates. The supported OS version depends on the device model.

  1. Confirm that the target version supports your device. Check available space under Settings, General, then iPhone Storage or iPad Storage.
  2. Connect to power and a reliable Wi-Fi network. If the download is slow, pause other large downloads.
  3. For an update-server or verification error, retry on a different Wi-Fi network. If the wireless attempt still fails, use the computer-based update procedure linked in Apple’s guide.

The forum report describes an update that stalled at the request stage. A reply suggested Wi-Fi, but the original poster did not confirm that it fixed the issue.

Mac · Reviewed 2026-11-11

Mac external display is blank or shows the wrong resolution

Check the display connection without a dock or hub first. This helps narrow down whether an adapter is limiting the signal.

Applies to Mac computers using external displays. The accessory prompt applies to Mac laptops with Apple silicon. Display limits vary by model.

  1. Check the monitor’s power and reconnect the video cable at both ends. If you use a dock or hub, try a direct connection to the Mac.
  2. Compare the resolution and refresh rate you want with the limits of the Mac, cable and adapter. If you use multiple screens, check the Mac’s supported display count.
  3. On an Apple silicon Mac laptop, unlock the Mac and approve the display if macOS prompts you. If you use the laptop with the lid closed, connect power and an external keyboard and mouse.
  4. If the display still isn’t detected, open Displays in System Settings and hold Option to reveal Detect Displays.

The community thread concerns black borders with one adapter. It illustrates why the adapter matters. Apple’s documentation provides the general steps above.

Mac · Reviewed 2026-11-11

Time Machine can’t use a network backup disk

Check whether the destination provides Time Machine over SMB. A NAS drive’s internal file system and the protocol macOS uses to reach it are separate settings.

Applies to Macs backing up to a NAS or another Mac. Apple documents that AFP backup destinations are unsupported in macOS 27 and later.

  1. For a NAS, check the manufacturer’s documentation for Time Machine over SMB and enable that feature for the intended share.
  2. For another Mac running macOS Ventura or later, open System Settings, then General, then Sharing. Open File Sharing options and mark the intended folder as a Time Machine backup destination.
  3. On the Mac being backed up, open System Settings, then General, then Time Machine. Add the supported destination and confirm that the first backup completes.
  4. If the existing destination uses AFP, retain the old backups while setting up an SMB destination or a directly connected disk. Verify the new backup before changing the old disk.

The discussion explains the distinction between a NAS file system and its network protocol. It does not establish that a particular Raspberry Pi or Samba configuration supports Time Machine.
